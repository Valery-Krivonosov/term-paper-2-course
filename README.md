# term-paper-2-course
console application for managing a transport company's logistics

## О проекте 
Программа решает задачу автоматизации распределения заказов между водителями и транспортом для диспетчера логистического отдела. Она помогает избежать простоя транспорта и назначает наиболее подходящее ТС в зависимости от веса груза и срочности.

## Сценарий 
Пользователь регистрирует в системе новый заказ с параметрами веса, пункта назначения и срочности. Система проверяет наличие свободных машин и водителей на складе и назначает рейс. В ходе рейса заказ проходит статусы «назначен», «в пути» и «доставлен», а водитель и машина становятся свободными.

## Запуск
### C++ (папка `VersionCpp`)

Для сборки требуется компилятор с поддержкой C++17.

```bash
# Переход в папку
cd VersionCpp

# Компиляция проекта
g++ cpp/*.cpp main.cpp -o 1.exe

# Запуск
./1.exe
```

### Java (папка `VersionJava`)

Для сборки требуется JDK версии 27 и выше.
```bash
# Переход в папку
cd VersionJava

# Компиляция проекта
javac *.java

# Запуск
java Main
```
