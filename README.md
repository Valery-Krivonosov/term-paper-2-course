# term-paper-2-course
console application for managing a transport company's logistics

## О проекте 
Программа решает задачу автоматизации распределения заказов между водителями и транспортом для диспетчера логистического отдела. Она помогает избежать простоя транспорта и назначает наиболее подходящее ТС в зависимости от веса груза и срочности.

## Сценарий 
Пользователь регистрирует в системе новый заказ с параметрами веса, пункта назначения и срочности. Система проверяет наличие свободных машин и водителей на складе и назначает рейс. Далее пользователь запускает симуляцию времени (такты), в ходе которой заказ проходит статусы «назначен», «в пути» и «доставлен», а водитель и машина становятся свободными.
